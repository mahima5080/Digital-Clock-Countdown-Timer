
# Digital Clock & New Year Countdown Timer — Web Development Week 2

## 📌 Project Overview
This repository contains the **Week 2 Web Development Assignment**. The project is an interactive, real-time **Digital Clock and Countdown Timer** built using **HTML5**, **Tailwind CSS**, and **JavaScript** (`Date()` API & `setInterval()`).

---

## 🛠️ Assignment Requirements & Features
* **Live Digital Clock**: Real-time updating display showing `HH:MM:SS` along with the day of the week and full date.
* **12-Hour / 24-Hour Format Toggle**: Interactive control buttons allowing users to switch dynamically between 12-hour (AM/PM) and 24-hour military time.
* **New Year Countdown Timer**: Real-time calculation counting down Days, Hours, Minutes, and Seconds remaining until midnight on January 1st.
* **Tab-Based View Switching**: Smooth navigation tabs allowing users to toggle between the Live Clock and Countdown Timer.
* **Glassmorphism UI**: Modern dark theme interface designed with backdrop blur effects, glowing digital typography, and responsive grid layouts.
